# Перевірка ЛБ2

Перевірено 24.11.2026 у вбудованому Chromium-браузері через локальний HTTP-сервер. Тестові дані вигадані.

## Адаптивність

| Viewport | Результат |
| --- | --- |
| 390 × 844 px | Одна колонка, мобільне меню, кнопки й поля доступні. Після виправлення gutter ширина документа дорівнює доступній ширині 375 px, горизонтального переповнення немає. |
| 820 × 1180 px | Hero в одну колонку, напрямки у дві, команда в три; меню згортається. Ширина документа 805 px дорівнює доступній ширині. |
| 1440 × 1000 px | Hero у дві колонки, чотири картки напрямків, три картки лікарів, повна навігація. Ширина документа 1425 px дорівнює доступній ширині. |

Різниця між viewport і доступною шириною відповідає смузі прокручування. Це емуляція розміру вікна, а не перевірка на фізичних телефонах чи в Safari/Firefox.

Скриншоти збережено в `screenshots/`: desktop — повна сторінка; mobile і tablet — видима область. Розміри файлів зображень можуть відрізнятися від CSS viewport через масштаб захоплення браузером. `preview.jpg` — верхня частина повного desktop-скриншота.

## Функціональність

- Мобільне меню відкривається; після вибору «Лікарі» переходить до секції та згортається.
- Кнопка картки Андрія Мельника обирає кардіологію та цього лікаря у формі.
- Зміна напрямку на педіатрію скидає попереднього лікаря й залишає Марію Бондар у списку.
- Сімейна медицина та УЗД показують Олену Коваль.
- Коректні тестові ім’я, телефон, лікар, майбутня дата та прапорець дають повідомлення про успішну перевірку без реального запису.
- Порожній необов’язковий e-mail не перешкоджає перевірці.
- Ім’я з пробілів та короткий телефон відхиляються через custom validity.
- Телефон із літерами відхиляється через HTML pattern, коректний телефон із пробілами й префіксом +380 приймається.
- Минула дата відхиляється через `min`, неправильний e-mail — через `type="email"`.
- Введення нового значення приховує попереднє повідомлення про результат.
- Усі внутрішні якорі, SVG-посилання та локальні файли перевірено на існування; ID унікальні, всі поля мають label.
- Чотири фотографії завантажилися успішно; CSS і JS Bootstrap підключені локально.
- Під час підсумкової перевірки браузер не повернув помилок чи попереджень консолі.
- `node --check script.js` завершився успішно.

## Валідатори

HTML перевірено фактичним POST-запитом до [W3C Nu Validator](https://validator.w3.org/nu/). Після виправлення помилки тегу option отримано **0 повідомлень** — без помилок і попереджень. Відповідь збережено в `validation/html.json`.

Перевірка власного CSS через [W3C CSS Validator](https://jigsaw.w3.org/css-validator/) не завершилася: POST повернув `IllegalStateException: Reader used`, повторний GET — HTTP 520. Успішну зовнішню CSS-валідацію не заявляємо. Перед здачею її можна повторити через File Upload сервісу. Відображення власних стилів перевірено в браузері на зазначених ширинах.
