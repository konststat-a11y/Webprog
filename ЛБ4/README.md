# Лабораторна робота №4. Bootstrap + JavaScript

Варіант 9 — приватний медичний центр «Лінія». Це окрема копія ЛБ2 з новою JavaScript-функціональністю; файли ЛБ2 не змінено.

## Як запустити

**Через подвійний клік на index.html завантаження JSON не працює через обмеження браузера. Потрібен HTTP-сервер.**

Найпростіший спосіб: відкрийте папку ЛБ4 у VS Code, встановіть Live Server та виберіть Open with Live Server для index.html. Альтернатива, якщо встановлено Python: виконайте в цій папці `python -m http.server 8000`, відкрийте `http://localhost:8000`. Після публікації на GitHub Pages сервер на комп’ютері не потрібен.

Під час підготовки запущено локальний перегляд `http://127.0.0.1:8769`. Після його завершення використайте один зі способів вище. Node.js, npm та збирання для запуску не потрібні. Bootstrap і фотографії локальні.

## Реалізовано

- `Promise.all`, `fetch`, `async/await`: паралельне завантаження doctors.json та services.json, перевірка HTTP-статусу й структури даних. Є індикатор завантаження, таймаут 12 секунд, обробка помилок і повторна спроба.
- Каталог генерується з JSON; спеціальності беруться з даних. Фільтрація зберігає початковий масив. Bootstrap Modal показує освіту, мови, досвід і розклад.
- Вибір лікаря зі списку, картки або профілю; доступні лише сумісні послуги. Календар визначає день тижня. Час нормалізується з 9:00 до 09:00.
- Минулі дні, години, що вже минули сьогодні, і зайняті слоти не пропонуються. Неділя без розкладу показує відсутність доступного часу.
- Перевірка ПІБ: не менше трьох слів із літер, апострофів і дефісів; частина імені повинна починатися й закінчуватися літерою, містити щонайменше дві літери. Телефон — строго `+380` та 9 цифр, без пробілів. E-mail необов’язковий.
- Помилки показуються під полями, фокус переходить на перше неправильне поле. Після перевірки відкривається окреме вікно підтвердження; кнопка «Редагувати» дозволяє повернутися без бронювання.
- Підтвердження займає слот; доступність перевіряється повторно. Повторне натискання кнопки не дублює запис.
- Калькулятор створює чекбокси з services.json, оновлює суму через reduce та готує перелік вибраних послуг до друку. Кнопка викликає стандартний window.print(); друкується лише розрахунок.
- Сценарний чат пропонує напрямок за темою й переводить до форми з уже вибраними лікарем та послугою. Це не зовнішній AI-сервіс.
- Делегування подій використане для динамічного каталогу; дані перед вставкою в HTML екрануються, контактні дані в підтвердженні вставляються через textContent.

## Збереження та обмеження

Слот зберігається в localStorage під ключем `linia-lab4-bookings-v1`. Зберігаються **лише doctorId, date, time**. ПІБ, телефон та e-mail не зберігаються і не надсилаються. «Очистити тестові записи» видаляє лише дані цього завдання. Якщо localStorage недоступний, працює пам’ять вкладки до перезавантаження.

Це навчальна клієнтська демонстрація, а не реальна система клініки. Немає спільної бази, авторизації, серверної перевірки чи гарантії від одночасного бронювання в різних браузерах/вкладках. Час визначається в локальному часовому поясі браузера. Один слот відповідає одній послузі; тривалість процедур не моделюється. Калькулятор незалежний від запису: вибір кількох послуг не створює кілька візитів.

## Перевірки

У браузері перевірено:

- Завантаження 3 лікарів і 6 послуг; фільтр кардіології залишає 1 картку; модальне вікно містить дані JSON.
- Перехід із модального вікна до форми підставляє лікаря і сумісні послуги.
- Неділя 10.01.2027 не має часу; понеділок 11.01.2027 пропонує кардіолога на 09:00, 10:00, 11:00.
- Підтвердження тестового запису на 09:00 прибирає цей час; після перезавантаження він також зайнятий. Після тесту записи очищено.
- Некоректні ПІБ, телефон, e-mail, минула дата, порожній час і відсутній прапорець дають помилки.
- Консультація кардіолога 950 грн + ЕКГ 450 грн = 1400 грн; скидання повертає 0 грн і вимикає друк.
- Консультант за темою огляду дитини рекомендує педіатра, кнопка підставляє його та послугу у форму.
- Через тимчасовий тестовий сервер перевірено порожні масиви, HTTP 404, некоректний JSON та повторний запит. Файли сайту для цього не змінювалися.
- На viewport 390, 820, 1440 px ширина документа дорівнює доступній: 375, 805, 1425 px відповідно. Мобільне меню працює.
- У підсумковій перевірці немає попереджень і помилок консолі; усі внутрішні якорі та локальні ресурси існують; `node --check script.js` успішний.
- W3C Nu Validator для фінального index.html: 0 помилок і попереджень.

Фізичні пристрої та принтер не перевірялися; друк реалізовано через стандартний діалог і CSS @media print. Надсилання SMS, e-mail чи заявки не реалізоване. Зовнішня CSS-валідація цього варіанта окремо не виконувалася.

## Gemini та публікація
