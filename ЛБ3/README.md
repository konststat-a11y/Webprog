# Лабораторна робота №3. Вступ до JavaScript

**Варіант 9.** Створення дерева для показу ієрархії. Натискання на посилання згортає або розгортає перелік підрозділів.

## Запуск

Відкрийте `index.html` у браузері. Інтернет, сервер, бібліотеки та встановлення пакетів не потрібні.

## Файли

- `index.html` — контейнер дерева й підключення CSS та JS.
- `style.css` — вигляд відповідно до фото: сірий фон, шрифт Times New Roman, сині підкреслені посилання та відступ підпунктів.
- `script.js` — дані ієрархії, створення вкладених списків і обробка натискань.

## Ієрархія

```text
fruits
  apple
  pineapple;
  apricot;
  pear;
  lemon;
vegetables
  potatoes;
  beetroot;
  carrots;
  pear;
```

Назви, порядок і крапки з комою збережено з наданого зразка. `pear;` у розділі `vegetables` залишено навмисно, відповідно до фото.

## Як працює код

1. Масив `hierarchy` містить об’єкти категорій та масиви дочірніх елементів.
2. `createTree()` створює `ul`, `li` та `a` через `document.createElement()` і додає їх через `appendChild()`.
3. Вміст вставляється як текст через `textContent`.
4. `addEventListener('click', ...)` реагує на натискання категорії.
5. `preventDefault()` скасовує перехід за якорем, тому сторінка не прокручується.
6. `list.hidden = !list.hidden` змінює видимість конкретного підсписку. Інша категорія зберігає свій стан.
7. `aria-expanded` повідомляє стан розділу допоміжним технологіям, `aria-controls` указує на відповідний список.

Початково обидві категорії розгорнуті. Посилання доступні клавішею Tab, натискання Enter також перемикає список. Код використовує базові теми наданих лекцій: змінні, об’єкти, масиви, функції, DOM і події. Інструкції та приклади вправ із лекцій не додано до завдання як окремі вимоги.

## Перевірка вручну

1. Після відкриття видно всі 5 елементів `fruits` і 4 елементи `vegetables`.
2. Натисніть `fruits`: зникають лише його 5 підпунктів.
3. Натисніть `vegetables`: залишаються тільки два посилання категорій.
4. Повторні натискання розгортають відповідні переліки.
5. Через Tab виберіть категорію й натисніть Enter: стан також перемикається.
6. Натискання звичайного текстового підпункту не згортає дерево.
