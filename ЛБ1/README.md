# Практична робота з вебпрограмування

## Запуск

Відкрийте `index.html` у браузері. Встановлювати програми або збирати проєкт не потрібно. Усі стилі та зображення локальні; сайт працює без інтернету, крім зовнішнього посилання на твір.

## Сторінки

| Файл | Призначення |
| --- | --- |
| `index.html` + `table.css` | Таблична верстка: `table`, `tr`, `td`, `rowspan="3"` |
| `float.html` + `float.css` | Плаваючі колонки: `float: left` і clearfix з `clear: both` |
| `inline-block.html` + `inline-block.css` | Колонки з `display: inline-block`, `vertical-align: top`; `font-size: 0` прибирає проміжки між елементами |
| `image.html` | Наданий малюнок свічки, `img` з `alt`, `figure`, `figcaption` |
| `form.html` + `form.js` | Анкета з перевіркою заповнення й локальним показом результату |
| `styles.css` | Спільні кольори, шрифти, рамки та оформлення |

У трьох варіантах однаковий вміст, але різні способи розмітки. Основні колонки не використовують Flexbox або Grid. Жовтий блок 2 займає всю висоту; праворуч розміщені синій блок 1, білий блок 4 та синій блок 3. Білі проміжки й чорні рамки відтворюють наданий шаблон. Ширина макета гнучка, максимальна — 1100 px; кольори збережено з фото.

Семантичні заголовки `h1`, `h2`, `h3` і абзаци `p` використано за змістом. Не потрібно штучно використовувати всі шість рівнів заголовків. Меню на кожній сторінці містить посилання на всі інші сторінки; поточна має `aria-current="page"`.

## Текст твору — обмеження пункту 2

Джерело: [Фрідріх Ніцше, «Так казав Заратустра», УкрЛіб](https://www.ukrlib.com.ua/world/printit.php?tid=3781).

Наразі на трьох сторінках розміщено коротку цитату з українського перекладу, власний стислий переказ початку та посилання на джерело. Повний переклад із зовнішнього сайту не скопійовано через авторські права. Тому вимога про заміну всього тексту текстом джерела виконана частково. Для дослівного оформлення більшого уривка надайте його як вхідний матеріал; його потрібно вставити в `article` усіх трьох сторінок, зберігаючи заголовки й абзаци.

## Поля форми

| Назва | name | Тип | Обов’язкове |
| --- | --- | --- | --- |
| Прізвище, ім’я, по батькові | `user_name` | `text` | Так |
| E-mail | `user_email` | `email` | Ні |
| Дата народження | `user_birthdate` | `date` | Так |
| Стать | `user_sex` | `radio`: `Чоловіча` / `Жіноча` | Так |

Порожні обов’язкові поля й неправильний формат заповненого e-mail перевіряє браузер. JavaScript показує результат без надсилання даних. Кнопка «Очистити» скидає поля та повідомлення. Серверна обробка й збереження не реалізовані: це статичне навчальне завдання для GitHub Pages.

## Лекції та Bootstrap

Враховано теми наданих лекцій: структура HTML5, семантичні елементи, заголовки й абзаци, посилання, малюнки, таблиці, форми, зовнішні CSS-файли та блокова модель. Завдання наприкінці лекції про Bootstrap є навчальним матеріалом, а не додатковою умовою цієї роботи. Bootstrap не підключено: тут потрібно показати саме таблиці, float та inline-block. Bootstrap можна додати окремо, якщо цього прямо вимагатиме викладач.

## Публікація на GitHub Pages

1. Створіть репозиторій і завантажте в його корінь **вміст** цієї папки: п’ять HTML-файлів, чотири CSS-файли, `form.js` і папку `assets`.
2. Відкрийте Settings → Pages → Deploy from a branch.
3. Виберіть свою гілку (зазвичай `main`) і папку `/ (root)`, збережіть налаштування.
4. Після публікації скопіюйте посилання, яке покаже GitHub Pages. Для здачі також потрібне посилання на репозиторій.

Публікацію виконуєте самостійно, відповідно до вашої вказівки.
